# 经核对的官方快照

`nbs-2026.html.gz` 是[统计局 2026 年发布日程原文](https://www.stats.gov.cn/xw/tjxw/tzgg/202512/t20251224_1962137.html)的原始响应，使用确定性 gzip 压缩。2026-10-30 北京时间 21:13 采集、21:16 核对；精确时间及未压缩正文 SHA-256 在 `nbs-2026.json`，正文为 399662 字节。解析得到 CPI、PPI、PMI、国民经济运行情况共 47 项，含 3 月两次 PMI、8 月经济运行情况 15:00 等特殊安排。回归测试逐项比较已核对的表格片段。

用户接受此方案用于主源不可达时初始化。启动只补缺、不覆盖已有事件、不更新主源成功状态；原文和核对记录写入独立 SQLite，详情可下载纯文本原文。主源未来成功时正常产生修订，历史快照证据继续保留。维护程序见 [snapshots.go](../snapshots.go)。
