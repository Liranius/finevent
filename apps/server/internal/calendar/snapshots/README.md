# 经核对的官方快照

## 国家统计局

`nbs-2026.html.gz` 是[统计局 2026 年发布日程原文](https://www.stats.gov.cn/xw/tjxw/tzgg/202512/t20251224_1962137.html)的原始响应，使用确定性 gzip 压缩。2026-10-30 北京时间 21:13 采集、21:16 核对；精确时间及未压缩正文 SHA-256 在 `nbs-2026.json`，正文为 399662 字节。解析得到 CPI、PPI、PMI、国民经济运行情况共 47 项，含 3 月两次 PMI、8 月经济运行情况 15:00 等特殊安排。回归测试逐项比较已核对的表格片段。

用户接受此方案用于主源不可达时初始化。启动只补缺、不覆盖已有事件、不更新主源成功状态；原文和核对记录写入独立 SQLite，详情可下载纯文本原文。主源未来成功时正常产生修订，历史快照证据继续保留。维护程序见 [snapshots.go](../snapshots.go)。

## 美国劳工统计局

取得 BLS 日历文件后，可在「设置 → 日历官方来源」选择 `.ics`，核对变更并确认导入。事件详情和修订历史保留该版本的文件。下述摘录维护流程适用于官方年表和公告。

`bls-2026.tsv` 和 `bls-2027.tsv` 收录 2026-11-16 能在 BLS 年表与各月清单交叉核对的全部带时刻发布，分别为 166 和 142 条。节假日行没有数据发布。每行保留美国东部日期、当地时刻、官方项目名和统计期。来源链接、摘录的 SHA-256、采集与核对时间见 [bls.json](bls.json)。[2026 年表](https://www.bls.gov/schedule/2026/home.htm) · [2027 年表](https://www.bls.gov/schedule/2027/home.htm)

劳工部托管的就业报告也可确认临近发布。11 月 6 日报告明确给出下一期非农的日期和时刻，对应 `bls-notice-11062026.tsv`。7 月就业报告说明 2026 年 3 月的最终基准修订随 2027 年 1 月非农发布。两项安排均沿用相应月报的事件和提醒。[11 月 6 日公告](https://www.dol.gov/newsroom/economicdata/empsit_11062026.pdf) · [7 月就业报告](https://www.dol.gov/newsroom/economicdata/empsit_08072026.pdf)

维护新年表时，逐月比对项目、统计期、日期和时刻，将四列写入 `bls-YYYY.tsv`，在清单中更新对应年份的 URL、条数、核对时间、摘要及 ID。新的劳工部公告经人工核对后，将明确给出的发布行写入 `bls-notice-MMDDYYYY.tsv`，使用该次就业报告的 PDF URL 追加清单。相同项目及统计期改期沿用原事件。旧摘录和历史版本保留在已导入的数据库中。清单与摘录随程序发布，启动时在同一事务中校验并导入。维护后运行 `pnpm test:go`。实现与回归见 [bls_schedule.go](../bls_schedule.go) 和 [bls_schedule_test.go](../bls_schedule_test.go)。
