# 正式日历数据通过独立数据包交付

日历年表会跨版本改期。把正式正文放在 Go 二进制中会使数据更新依赖重新部署。维护者决定将已核对的官方日程独立打包，代码库保留解析器和回归样本。

## Observations

- [decision] 新实例以官方同步初始化。需要离线补充时，由维护者核对并导入独立 ZIP。格式和命令见 `docs/calendar-package.md`。
- [consequence] 原文、关注和修订留在部署数据库，验收对照升级前备份核查既有事件、修订和关注。导入记录与主源同步状态分别判断。
