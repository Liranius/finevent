# 零售销售与初请日程使用发布机构的一手安排

现有纽约联储适配器收录指定 BLS 项目。样本 `apps/server/internal/calendar/testdata/nyfed-nov2026.html` 把感恩节当周的初请列在周五，劳工部的例外表列在周三。若直接放宽纽约联储筛选，提醒可能晚两天。人口普查局的零售销售表还给出了统计月份，可用来识别跨月改期的同一期发布。

## Observations

- [decision] 分别从人口普查局和劳工部同步零售销售初值和初请日程，保留各自的原文链接、成功时间和错误状态。
- [constraint] 零售按统计月识别，初请按常规发布周识别。节假日例外替换该周时间，已有关注跟随同一事件。
- [consequence] 两个主源参与日历部署验收。零售销售的补充来源与 403 验收条件见后续决策。旧版报告按当时具备的来源核查。

适配范围见 `docs/calendar-api.md`。原始安排见[人口普查局零售时间表](https://www.census.gov/retail/release_schedule.html)和[劳工部每周发布安排](https://oui.doleta.gov/unemploy/claims_arch.asp)。
