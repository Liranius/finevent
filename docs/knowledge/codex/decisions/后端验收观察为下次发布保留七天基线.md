# 后端验收观察为下次发布保留七天基线

一次后端发布完成最终重启后，新闻或日历验收的连续采样可以同时证明当前后端适合作为下次部署的起点。把证据摘要写入已审核的后端报告，可以省去相邻两次发布间重复的 65 分钟等待。

- [decision] 七天内，复核原始持久化证据、运行进程身份、配置、完整采样及之后的内存记录后可直接复用。缺失、过期或不再适用时，安装前重新做只读观察。
- [constraint] 新 OOM 和已发现的内存压力会阻断安装。交互式 AI 的末次重启发生在付费请求之后，只读窗口从该次重启后开始。
- [scope] 纯前端发布和回退沿用独立发布记录，保留后端证据及其原有效期。
