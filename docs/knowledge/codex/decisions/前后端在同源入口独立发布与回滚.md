# 前后端在同源入口独立发布与回滚

原发布包将页面和 Go 程序放在同一版本目录，页面改动也会停服务、备份数据库并进入后端观察。保留现有仓库和站点来源，由 Nginx 托管静态版本，Go 负责 API 与采集。仅拆开压缩包仍会共用运行时或回滚指针，因此构建、安装和操作记录一起拆开。

## Observations

- [decision] Web 和 Server 分别构建、发布与回滚，并在同一 PR 中运行跨端验证。
- [constraint] 前端更新只切换静态目录。后端继续使用已审核的前序、备份及后台观察。
- [constraint] 接口演进需兼容已安装的旧 PWA 和可回滚的前端版本。
- [branch] codex/split-web-server-releases
