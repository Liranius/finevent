# DeepSeek 事件解读

新闻详情和“AI 解读”设置已部署，单次真实业务调用及并行采集验收已完成；持续自动解读负载仍待验收，记录见 [实施状态](implementation-status.md)。模型默认 `deepseek-flash`，关闭思考，不启用搜索或工具；模型及价格可在服务端配置。新闻、日历和规则分类独立运行。

## 开启与范围

默认关闭。设置提供总开关和“自动解读新的重要报道”：开启后从当前新闻变更水位开始，只处理新入库、非基线历史条目、入库不超过一天且规则重要性为 3 的报道及其修订。历史新闻不批量追补，其他报道可在详情手动请求。暂停保留队列，已经发出的请求可能完成。

单个持久化队列同时只执行一个模型调用，与旧验证探测共用调用锁；待处理最多 100 项。模型调用最长 45 秒，输出最多 3,072 token，响应上限 512 KiB。模型故障不阻塞新闻读写；失败后全局退避五分钟，鉴权、余额或用量异常暂停 AI。失败请求不自动重发，用户可以核对后手动重试，每份输入最多三次。进程中断的未完成调用标为“待核对”，保留费用预留。

输入包含当前报道及最多两份相同 URL/正文的跨源报道，相似标题不自动作为解读证据。每份标题最多 400 字、正文最多 5,000 字，截取会显式标记。缓存键覆盖模型、提示词版本以及去重排序后的输入标题、正文、URL、发布时间；复用时保留原引用快照和署名，不冒充再次调用。排队期间内容发生变化则停止旧任务，用户可请求最新版本；已完成解读遇到来源修订标为旧版本。

## 输出与证据

事实摘要附逐字引文及快照编号，潜在影响按市场、行业和对象分别列出利好、利空、混合或不确定，以及路径、条件、期限、反向因素。指标实际值、预期值和前值必须包含来源及逐字引文，缺失用 `null` 表示；不从缺失值推算数值。

只接受完整 JSON、已知类别和方向、存在的引用、能在快照找到的引文及数值。输出为空、截断、引用不存在或用量无效时显示未完成，不展示为成功解读。引用存在性检查不等于语义事实核查，推断可能出错；本批没有行情关联或走势预测。

解读和输入快照独立于普通新闻清理，保存至少一年（完成调用时延长）；费用账本不随新闻或解读删除。历史页列最近 20 项，单条详情可按解读 ID 读取。回滚时暂停 AI，并将失败版本冻结数据库中的业务/探测费用记录保留到恢复后的数据库，避免回退释放已发生费用；冲突身份拒绝覆盖并保留证据。

## 月预算与价格

按北京时间月份限制为 30 元，使用整数纳元存储。调用前以完整输入 JSON 的 UTF-8 字节数加消息封装余量、输出 token 上限和配置高峰价预留；单事务检查余额及写入调用记录。`ai_budget_entries` 统一汇总业务 `ai_calls` 与既有 `ai_probe_runs`，不重复导入历史费用。

返回有效用量后按 token 和价格配置估算，即使内容校验失败也计费；缺失缓存用量按未命中估算。超时、响应损坏、HTTP 错误或用量缺失时保留全部预留。余额不足时任务等待下月额度；历史费用仍保留。月末最后一分钟不开始新的业务请求，避免 45 秒请求跨月。此预算仅覆盖 finevent 的调用，非整个 DeepSeek 账户额度。

2026-11-01 核对的 [DeepSeek 官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)：Flash 高峰输入未命中/命中/输出为每百万 token 2/0.04/8 元；空闲时段减半。当前默认仅在请求完整处于确定的空闲时段时减半；跨越价格边界按高峰上界。周末及非高峰时间可直接判断，法定节假日可由配置 `holiday_year`、`holidays` 补充；未维护时，工作日高峰可能高估。调用记录保存价格版本、时段依据、用量和估算，界面不将其称为实际账单。

## 配置

密钥不经浏览器或 API 设置。部署后，在服务器以 finevent 服务账户运行当前二进制的 `-configure-ai -data /srv/example/finevent-data`，终端隐蔽输入密钥；写入私有 `ai-config.json`。配置文件需归服务账户所有、权限 0600，不上传源码、发布包或报告。重启服务加载配置，再在页面开启。首次使用前先按本批发布验收步骤核对资源，不能直接用日历/新闻观察代替 AI 负载验收。

配置字段：`api_key`、`model`、`peak_pricing`（`version`、`input_nano_per_token`、`cached_nano_per_token`、`output_nano_per_token`）、`off_peak_half`、`holiday_year`、`holidays`、`prices_valid_until`。默认价格复核日期为 2026-12-01，北京时间当日 00:00 起暂停调用；复核官方价格后更新配置和日期并重启。配置缺失、无效或过期时新闻和日历继续运行。换模型必须同时核对其价格，旧模型的未发送任务标为配置变化，不自动改用另一模型执行。

## API

均要求已有会话，写请求校验来源，响应 `no-store`。前端可见时每 30 秒读取状态，保留未保存设置和操作错误。

| 方法与 `/finevent/api/v1/` 路径 | 内容                                                                  |
| ------------------------------- | --------------------------------------------------------------------- |
| `GET ai`                        | 开关、配置是否就绪、月预算/估算/预留/探测占用、积压和最近任务；无密钥 |
| `PUT ai/settings`               | `{enabled, automatic}`；启用前验证配置，改变开关重置自动采集水位      |
| `GET news/{id}/analysis`        | 当前关联任务、来源是否修订；没有任务返回 `{job:null}`                 |
| `POST news/{id}/analysis`       | `{retry:false}` 请求或复用；明确重试失败任务用 `true`，返回任务 ID    |
| `GET ai/analyses/{id}`          | 解读、冻结来源和调用费用记录；新闻清理后仍可读取有效期内快照          |

## 发布验收

首次生产接入使用 `scripts/publish-ai.ps1`，明确指定已核验的 `-Archive` 和上一签收的 `-AfterReview`。与日历/新闻发布共享锁、操作指针和回滚流程。只允许既有业务 AI 未配置、暂停且无任务/账目的首次接入；已有配置或失败操作必须先审核，不能重复运行发布。

1. 校验发布包和前序记录，再通过已校验程序的 `-configure-ai` 读取终端隐蔽输入。密钥先写入操作目录私有文件，安装后以 0600、finevent 账户归属落入服务数据目录；临时副本删除。不经过进程参数、环境变量、报告或浏览器。
2. 备份与迁移保留原探测费用；启用统一账本，验证新闻迁移、分类索引及重启后配置可用。剩余预算不足 0.50 元时不发起验证调用。
3. 最多等待 32 分钟，检测正常 TrendRadar 采集的新进程身份，不修改其定时任务。选择近一天、具备正文和原文链接的真实华尔街见闻报道，只请求一次、不自动重试。领取任务后立即暂停后续调用；失败、SSH 断开或缺少并行证据都不重发。
4. 模型请求记录毫秒级网络起止时间，采集进程 PID 与启动标识并存，100 毫秒采样区间完整落在请求内才计为重叠。普通阶段每五秒采样；资源阈值不变。模型结束后观察五分钟正常采集，检查结果、引用校验、月预算、新闻/原网页健康，再重启核对解读、快照、费用及时间记录不变。
5. `scripts/publish-ai.ps1 -Report` 仅下载进度或终态，不部署、不调用模型。只有结果有效、用量已知且费用估算在预留内、预留不超过 0.50 元、实际重叠和资源检查通过，机器报告才待签收；内容是否合理仍需两端人工核对。自动解读保持关闭，签收后再开启。

回滚保留最新业务数据、实际费用和未知预留，暂停 AI；已写入的服务器私有密钥保留，不包含在下载报告中。来源文本或调用状态有问题会留下证据待审核，不把缺失输出算作通过。

本批只验证一个真实输入与一次正常 TrendRadar 采集重叠，以及相邻正常 finevent 采集周期；不声称覆盖所有请求恰好同时在途、整月持续调用或其他新闻类型。长期负载 TODO 仍见实施状态；日历下一个六小时同步不重复测试。

## 验收边界

本地用明确测试夹具覆盖模型响应、失败及预算边界；浏览器测试验证真实页面交互，不能替代真实 DeepSeek 输出质量、服务器峰值和双端业务验收。生产已完成一次小额真实业务调用的输出、用量、证据和并发采集资源核对；持续自动解读的负载边界仍见 [实施状态](implementation-status.md)。[新闻自动推送](news-push-api.md) 也已接入，实际设备验收及尚未覆盖的场景由实施状态维护。
